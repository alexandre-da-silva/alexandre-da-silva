# Alexandre da Silva Santana

Sou estudante de Análise e Desenvolvimento de Sistemas na UNIAGES e busco minha primeira oportunidade em desenvolvimento back-end. Java é a linguagem que mais uso. Comecei com aplicações de terminal e hoje também desenvolvo APIs com Spring Boot e trabalho com bancos de dados relacionais.

## Conhecimentos técnicos

- **Java e orientação a objetos** — organizo o código em classes e métodos, uso coleções e implemento validações de entrada e regras de negócio.
- **Spring Boot** — desenvolvo APIs REST e separo o código que recebe as requisições, aplica as regras de negócio e acessa os dados.
- **SQL e MySQL** — modelo tabelas com chaves primárias e estrangeiras e escrevo consultas para cadastrar, buscar, atualizar e excluir registros.
- **Interfaces** — crio telas de desktop com Java Swing e tenho conhecimentos básicos de HTML, CSS e JavaScript.
- **Ferramentas** — uso Git e GitHub para versionar código, Postman para testar endpoints e MySQL Workbench para trabalhar com o banco de dados.
