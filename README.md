# Alexandre da Silva Santana

Sou estudante de Análise e Desenvolvimento de Sistemas na UNIAGES e busco minha primeira oportunidade em desenvolvimento back-end com Java. No meu projeto atual, uso Spring Boot e MySQL para trabalhar com um problema do dia a dia de um restaurante. O desafio é acompanhar um pedido desde a escolha do prato até o preparo na cozinha.

## Projeto em destaque

### [AstraChefe · Sistema de gerenciamento de restaurantes](https://github.com/alexandre-da-silva/sistema-de-gerenciamento-de-restaurante)

No AstraChefe, o cliente consulta o cardápio, faz um pedido e acompanha o andamento. A equipe da cozinha recebe o pedido e atualiza a etapa de preparo. É um projeto acadêmico em desenvolvimento.

Três exemplos do que estou praticando no back-end.

- **Regras de negócio** — validar as mudanças de status para que um pedido siga as etapas previstas.
- **Controle de acesso** — usar Spring Security e JWT para que cada cliente consulte seus próprios pedidos e a cozinha acesse o painel de preparo.
- **Banco de dados** — relacionar pedidos, itens e produtos no MySQL e versionar as mudanças de estrutura com Flyway.
